# University-program-page-parsing

## Task Description

Parse for the program url for 400+ national universities
Save one csv file contianing each university's name, program url, program url XPath

To run the project, Create a Gemini API key and adjust it to api_key

An output csv file should be adjusted to the OUTPUT_CSV_PATH
Make sure to change the paths to an actual path on your machine.
